## 03 · 宣传物料设计

这套作业里工作量最大的一块，分三条线：

- **海报** 6 张：招聘、宣传、品牌态度、发布会邀请、体验店开业、联动外星人

## 想拿去做自己的作业？

这是一套**完整的虚拟品牌案例**，不是填模板。真要参考，建议这么做：

1. **换品牌名和主色**，别沿用 NIGHTLI 的黑金鹰标
2. **只借鉴结构**：品牌定位 → 标志 → IP → 物料 → 动态内容 → 报告，这条链路本身是课程要求的完整度
3. **图片全部重做**，用你自己的 AI 生成结果覆盖同名文件
4. **报告和提案重写**，AI 生成的文字痕迹很明显，原样交会被看出来

仓库里唯一"拿来就能跑"的是根目录的小程序 Demo，改法见仓库根目录的 README。
