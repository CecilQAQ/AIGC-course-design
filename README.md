
# NIGHTLI — 20 页赛车 App 视觉案例（纯静态 · 双击即开）

一整个手机 App 的界面，全在 **一个 `index.html`** 里。下载解压，双击就能点，不用装 Node、不用装 HBuilderX、不用起本地服务器。

```
下载 → 双击 index.html → 20 个页面随便点
```

## 这是什么

| | |
|---|---|
| 技术 | 原生 HTML + CSS + JavaScript，**无框架、无构建、无依赖** |
| 结构 | 375×812 的手机外壳，内存状态机切换 20 个页面 |
| 网络 | 无 CDN、无外链、无 fetch，**断网也能跑** |
| 体积 | 约 1.2 MB，图片已压缩 |
| 来源 | AI 生成初稿 + 人工调整，用于课程作业 / 作品集展示 |

## 直接看

1. 点右上角 **Code → Download ZIP**，解压
2. 双击 `index.html`

> ⚠️ 必须**整个文件夹**一起打开。`index.html` 用相对路径引用 `assets/` 里的图片，只拷这一个 html 会满屏裂图。

## 目录

```

```

## 拿来改成你自己的作业

改这五处就够了，都在 `index.html` 里：

**1. 品牌名** — 全文搜索 `NIGHTLI`（34 处），全局替换成你的项目名。记得连 `<title>` 一起改。

**2. 主色** — 搜 `#f43f5e`（玫红强调色，3 处），换成你的主色。整体基调是黑 `#111` + 白 `#fff`。

**3. 图片** — `assets/images/` 里 12 张，**用同名文件覆盖**即可，不用动代码。建议宽度 800px 左右、JPG 质量 80，控制体积。图标同理，`assets/icons/` 8 个 PNG，128px 以内。

**4. 文案** — 20 个 `function xxx()`，每个函数开头就是这个页面的 HTML，中文字符串直接改。

**5. 用户名** — 首页的 `Hi, Jonathan!`，换成你的名字。

### 想在真机上看全屏？

页面外面的手机边框是 `.phone` 这个类（`width:375px; height:812px; border:10px solid #090909`）。在手机浏览器里打开时，把它的 `border`、`border-radius`、固定宽高去掉，就变全屏 App 了。

## 已知限制

这些不是 bug，是刻意的简化，用之前心里有数：

- **刷新回首页**。没有 `localStorage`，状态只存在内存里，加进购物车的商品刷新就没了。
- **没有深链接**。不写 `location.hash`，所以没法把"第 13 页"的地址发给别人。
- **登录 / 注册 / 支付全是假的**。输入框不校验，点按钮直接跳下一页，纯前端演示。
- **图片是压缩过的展示素材**，不是原始高清图。
